# Weakly / Semi / Self-supervised（弱 / 半 / 自监督）

> **定义**：降低点级标注依赖的监督范式——弱监督（仅图级总数 / 框等弱标签）、半监督（少量标注 + 大量无标注）、自监督（无人工标签预训练后迁移计数）。
>
> **收录边界**：以"监督范式本身"为主要贡献的工作；其底层回归技术（密度图 / 检测等）不作为归类依据。
