# Point Supervision（点监督 / 定位计数）

> **定义**：在点标注监督下直接回归目标中心点或定位热图，通过检测到的中心点数量计数，不构建完整密度图。
>
> **收录边界**：以中心点 / 关键点定位为监督信号。用高斯密度图积分的归入 [Density_Map](Density_Map.md)。
