# Detection-based（检测后计数）

> **定义**：先用目标检测器框出每个个体，再通过统计检测框数量得到计数；稀疏场景下定位与计数可同时完成。
>
> **收录边界**：以检测器（两阶段 / 单阶段 / DETR 类）输出框再计数为主要路线。密集遮挡导致检测失效、转而用密度图的，归入 [Density_Map](Density_Map.md)。
