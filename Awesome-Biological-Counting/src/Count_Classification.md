# Count Classification（计数分类）

> **定义**：把数量离散化为若干区间 / 分箱（如 0、1、2、3、4+），以分类而非连续回归的方式预测计数。
>
> **收录边界**：以数量分箱分类为主要建模方式。输出连续标量的归入 [Direct_Regression](Direct_Regression.md)。
