# Density Map（密度图回归）

> **定义**：将每个目标中心点用高斯核扩散成密度图，训练网络回归整图密度图，再对密度图积分得到个体总数。这是人群计数的主流范式，也是密度估计方向最相关的一类。
>
> **收录边界**：以"生成并回归密度图"为主要技术路线的工作。只做点回归而不显式构建密度图的，归入 [Point_Supervision](Point_Supervision.md)。
