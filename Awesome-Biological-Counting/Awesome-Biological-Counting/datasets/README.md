# Datasets（数据集收集）

> 计数任务常用公开数据集汇总。只收录**公开可获取**的数据集，链接必须真实可达，不编造下载地址。

## 收录标准

- **公开可获取**：注明是否公开直接下载、是否需要注册 / 邮件申请 / 签协议。
- **标注类型 Annotation**：Point（中心点）/ Box（检测框）/ Image-level（仅图级总数），可组合，必须标清。
- **规模 Scale**：写清口径（多少张图像 / 多少标注个体），不写笼统的"大规模"。
- **划分 Split**：写明官方训练 / 测试划分方式；无公开划分则注明。
- 跨对象数据集在 Subject 栏写多个对象。

### 字段说明

- **Subject**：人 / 鸟 / 鱼 / 昆虫 / 海洋哺乳动物 / 红外相机兽类 / 细胞微生物等，可多个。
- **Scene**：监控 / 航拍 / 水下 / 红外相机 / 显微镜 / 野外地面等。
- **Scale**：如图像数 / 标注个体数，注明单位。
- **Annotation**：Point / Box / Image-level，可组合，如 `Point + Image-level`。
- **Split**：官方 train/val/test 划分；无则写 `未公开`。
- **Paper**：数据集原始论文链接；**Link**：下载页 / 项目主页。
