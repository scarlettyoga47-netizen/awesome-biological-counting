# Metrics（常用评价指标）

> 计数任务常用评价指标定义。公式为标准定义；**具体以各论文采用口径为准**，不同论文个别指标定义可能不同，引用时注明。

## 一、计数回归指标（三大主干通用，最常用）

### MAE（Mean Absolute Error，平均绝对误差）

- 公式：`MAE = (1/N) Σ |yᵢ − ŷᵢ|`
- 方向：**越低越好**。
- 说明：计数任务第一主指标，反映平均计数偏差，对异常误差不敏感。

### MSE（Mean Squared Error，均方误差）/ RMSE

- 公式：`MSE = (1/N) Σ (yᵢ − ŷᵢ)²`；`RMSE = √MSE`
- 方向：**越低越好**。
- 说明：对大误差平方放大，惩罚高估 / 低估较多的样本，常与 MAE 并列报告。

### MDE / 平均相对误差（Mean Deviation / Relative Error）

- 公式：`(1/N) Σ |yᵢ − ŷᵢ| / yᵢ`
- 方向：**越低越好**。
- 说明：按真实数量归一化的相对误差；**各论文口径略有差异**，引用时核对定义。

## 二、检测 / 定位计数指标

### Precision / Recall / F1

- 说明：检测框或中心点按 IOU / 距离阈值匹配后计算。
- Precision = TP / (TP + FP)；Recall = TP / (TP + FN)；`F1 = 2·P·R / (P+R)`。
- 方向：**越高越好**。

### AP（Average Precision，点定位平均精度）

- 说明：点标注按匹配距离阈值统计的平均精度。
- 方向：**越高越好**。

## 三、视频时序计数指标

### MOTA（Multiple Object Tracking Accuracy）

- 说明：用于检测 + 跟踪去重的视频计数，衡量跨帧跟踪与计数一致性。
- 方向：**越高越好**。
