# Contributing

感谢你愿意补充本合集。提交前请先阅读以下收录标准与格式约定。

## 收录范围

- 任务：用图像 / 视频做**个体计数**（counting），输出总数，或同时给出位置（密度图 / 点 / 框）。
- 对象：人以及其他生物（鸟、鱼、昆虫、海洋哺乳动物、红外相机兽类、细胞、微生物等）。
- 类型：正式发表的论文（会议 / 期刊 / arXiv）、公开数据集、官方开源代码。
- 不收：纯检测、纯分割但不做计数的工作；无法访问的死链；虚构或未公开的代码。

## 分类原则（主轴：方法）

1. 一篇论文只归入**最主要**的一种方法，不在多个分类下重复出现。
2. 若一篇工作同时使用多种技术，按其**核心创新 / 主要贡献**归类；拿不准时在 PR 里说明理由，由维护者裁定。
3. 方法分类见 [README.md](README.md) 的 Papers 矩阵；新增分类需先在 README 与对应 `src/*.md` 中同步建立。

## 条目格式

统一使用以下格式，放入对应方法文件的列表中：

```markdown
- <a name="缩写"></a>**[缩写]** 论文标题（**会议/期刊, 年份**）[[paper](paper链接)][[code](代码链接，无则省略)]
```

填写要求：

- `缩写`：论文常用简称（如网络名），全局唯一，用于 `#缩写` 锚点。
- `会议/期刊`：用通用缩写，如 CVPR / ICCV / ECCV / NeurIPS / ICLR / AAAI / TPAMI / TIP。
- 链接必须真实可达：paper 优先 arXiv / 官方开放获取；code 只填官方仓库，非官方复现需标注 `unofficial code`。
- 没有代码就不要硬写 `[code]`，更不要编造仓库地址。

## 数据集条目格式（README 的 Datasets 表）

| Dataset | Subject | Scene | Scale | Annotation | Link |
| --- | --- | --- | --- | --- | --- |

- Scale：样本图像数量 / 标注个体数量，写清口径。
- Annotation：Point / Box / Image-level，可组合。

## 提交流程

1. Fork 后在对应 `src/方法.md` 末尾追加条目，保持字母 / 年份顺序由维护者统一。
2. 新增数据集填 README 的 Datasets 表。
3. PR 说明：论文标题、年份、归入哪个方法、paper/code 链接核验结果。
4. 合并前逐条核验链接可打开，避免死链。
